# Домашнее задание: hw-01-basic-kotlin

## Описание

ДЗ по базовому Kotlin: синтаксис, ввод/вывод, циклы/алгоритмы, коллекции и стандартная библиотека.

README — это индекс. Полная спецификация задач и примеры находятся в комментариях (KDoc) прямо в исходниках рядом с `TODO()`.

## Как сдавать домашку

1. Решайте задачи по порядку.
2. Реализуйте недостающий код в местах, отмеченных `TODO()`.
3. Сделайте и запушьте коммит.
4. Убедитесь, что создался ПР, отработал `check-solution` action и в PR появился комментарий с результатами и баллами.
5. Призовите вашего практика на ревью.

## FAQ

### Как запускать тесты

Из корня репозитория:

```bash
./gradlew test
```

Запуск тестов для конкретного модуля:

```bash
./gradlew :task-01:test
./gradlew :task-02:test
./gradlew :task-03:test
```

### Как запускать приложения (task-01/task-02)

Через терминал (из `homeworks/hw-01-basic-kotlin`):

```bash
./gradlew :task-01:run --args="Alice"
./gradlew :task-02:run
```

`task-03` — это набор функций (без консольного приложения), его не нужно запускать через `run`.

### Как запустить через IntelliJ IDEA

- Откройте Gradle Tool Window
- Выберите `hw-01-basic-kotlin` → нужный `task-XX`
  - для `task-01`/`task-02`: `Tasks` → `application` → `run`
  - для `task-03`: `Tasks` → `verification` → `test`
- Для `task-01` укажите **Program arguments** (например: `Alice`)

### Тесты падают, но я не понимаю почему

Посмотрите на имя теста и текст ошибки (assertion message): обычно там описано ожидаемое поведение.
